# Handoff: U4-progress

Progress, Settings and Licences screens, built against the fakes. Class names and
constructors are unchanged (`ProgressScreen()`, `SettingsScreen()`, `LicencesScreen()`;
`LicencesScreen` gained an optional `entries` parameter). Colours come only from
`Theme.of(context)` and `ScoreColors.of(context)`, charts included.

## What was built

**Progress** (`lib/ui/progress/`)

- Summary card: level (of 6), streak, minutes today against the goal.
- Score trend: fl_chart line of the last 30 overall scores, dashed bands at 80 (good)
  and 60 (close) in the score colours, latest / best / average, semantic summary.
- Level history: current level and each `LevelChange` (newest first, date and reason).
- Sounds, weakest first: IPA, bar coloured by band, score, and an icon per band
  (tick / triangle / error) so colour is not the only cue. Light-tier users with no
  sound stats see "Per-sound scores need the full model".
- Streak calendar: last 5 weeks, Monday first; practised days filled with a tick,
  today outlined.
- States: loading, error with retry, empty (new user, "Start today's passage" goes
  Home), data. Two columns from 700 dp wide (tablets). Refreshes on every
  `ProgressRepository.changes` event (`progressDataProvider`).

**Settings** (`lib/ui/settings/`)

- Daily goal (5 / 10 / 15 / 20 / 30 min), daily reminder switch and time picker,
  passage text size slider (80-160 %, with a live preview; saved on release to
  `UserProfile.textScale`), keep recordings.
- Scoring model: Auto / Light / Full (Full enabled once downloaded; saved to
  `tierOverride`), recommended tier, full-model download with size, progress
  (MB and %), waiting for Wi-Fi, verifying, cancel, resume after cancel, retry after
  failure, Wi-Fi only switch (default on) and delete with confirmation (resets a Full
  override to Auto).
- British voice: voice name and "Play a sample", or install guidance for Android /
  iPhone with "Check again"; loading and error states.
- Your data: export (dated `uk-coach-progress-YYYY-MM-DD.json`), import (confirm,
  pick, `importJson`, reschedule reminder; a bad file shows "That file isn't a progress
  backup"), delete all data (confirm; cancels the reminder).
- Licences link (go_router push to `AppRoutes.licences`, Navigator fallback).
- Settings loading and error states.

**Licences**: every shipped model, dictionary, voice, content set, engine (ONNX
Runtime) and font from `lib/ui/settings/licence_data.dart`, seeded from the "Shipped"
table in `docs/licences.md`, plus "Open-source packages" (`showLicensePage`). A test
checks the main components named in docs/licences.md appear on the page.

**Adapters** (fakeable, overridable providers):

- `ReminderScheduler` / `reminderSchedulerProvider` (`reminder_scheduler.dart`).
  Default `UnavailableReminderScheduler`: see "Known gaps".
- `BackupFiles` / `backupFilesProvider` (`backup_files.dart`), implemented by
  `PlatformBackupFiles` on file_picker's platform interface.

## Known gaps

- **Reminders do not fire yet.** Waiting for the `dbus` allowlist decision
  (docs/contract-requests/U4-progress.md, request 1). Until then the reminder switch is
  disabled with an explanation. The drop-in implementation and native steps
  (desugaring, boot receiver, iOS delegate; inexact alarms, no exact-alarm permission)
  are in the request.
- **File dialogs not verified on a device** (no emulator here): using
  `android_file_picker` / `file_picker_darwin` without the `file_picker` app package
  relies on their `dartPluginClass` registration (request 3).
- Reminders are only scheduled when the setting changes or a backup is imported; I1
  should reschedule on start-up (request 4).
- Text size is stored here; U2 / U3 must apply `textScale` to passage text.
- Licences page data is hand-kept: update `licence_data.dart` when docs/licences.md
  rows land (Silero VAD, Britfone file names, any Piper voice, any bundled IPA font
  from U1).
- Sound list shows every stat; with many phonemes it could be capped
  (`SoundAccuracyList(limit:)` exists).
- Strings are English only (no l10n setup in the app yet); dates use a small built-in
  British formatter.
