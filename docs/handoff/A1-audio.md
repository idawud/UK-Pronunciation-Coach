# Handoff: A1-audio

`CoachAudioRecorder` implements `AudioRecorder`. It streams 16 kHz mono 16-bit PCM
from the `record` plug-in into a WAV file in app-private storage
(`<app support>/recordings/rec_<utc stamp>_<n>.wav`). While it records it emits the
level stream (20 values/s), runs Silero VAD on each 32 ms chunk to fire
`silenceDetected` (2 s of silence after at least 250 ms of speech), and keeps the
per-chunk probabilities. `stop()` returns the clip with `quality`, `peakDbfs` and
`snrDb`. Microphone permission goes through `permission_handler`.

## How to use it

```dart
final recorder = CoachAudioRecorder.platform(); // record + permission_handler + bundled Silero
if (await recorder.checkPermission() != MicPermission.granted) {
  await recorder.requestPermission();          // permanentlyDenied -> openPermissionSettings()
}
await recorder.start();                        // throws MicPermissionException / StateError
recorder.level.listen(waveform.add);           // 0..1, linear in dBFS from -60 to 0
recorder.silenceDetected.listen((_) => stopReading());
final clip = await recorder.stop();            // clip.quality: ok / tooQuiet / tooNoisy
final speech = await recorder.speechSegments(clip);
```

- **I1 wiring** (`lib/core/providers.dart`): see contract request 4.
- **e2e / fixture audio**: `CoachAudioRecorder(mic: FixtureMicSource.wav(wavBytes),
  permissions: FixedMicPermissions())`. `FixtureMicSource` plays the WAV in real time
  (20 ms blocks), then digital silence, so `silenceDetected` fires as it would on a
  phone. Pass `realTime: false` to deliver the clip at once.
- `speechSegments` on the clip just recorded reuses the live probabilities (0 ms).
  It caches the last 4 clips. Other files (e.g. fixtures) are analysed in a
  short-lived background isolate.
- Files and seams: `lib/engine/audio/README.md`. Barrel: `lib/engine/audio/audio.dart`.

| Silero VAD v6.2 (`silero_vad.onnx`, 2,327,524 B, sha256 `1a153a22…88e3`) | v6.2 tag | MIT | Run on the ONNX Runtime that **`onnxruntime_v2`** (A2's dependency, MIT) already ships |

**No `sherpa_onnx`.** It bundles its own ONNX Runtime, and two copies in one app risk
symbol clashes. `silero_vad.dart` calls the ORT C API through `onnxruntime_v2`'s
generated bindings, the same way A2 does, but with its own code: nothing is
imported from `lib/engine/runtime/`. No new transitive packages are MPL, GPL or AGPL;
the licence check passes.

### Silero model: not committed

`assets/models/*.onnx` is git-ignored and the folder belongs to A2/A4. The app loads
`assets/models/silero_vad.onnx` through `rootBundle`. **If that file is missing or does
not load, the recorder falls back to `EnergyVadBackend`** (RMS against an adaptive
noise floor; it works on the fixtures but treats any loud sound as speech).
Contract request 1 asks for a manifest entry so `tools/ci/fetch_models.py` bundles it.
Contract request 2 asks for the licences row.

- **Silero on the shared fixtures** (real model, if cached):
  - Python reference and Dart give identical probabilities.
  - `clean_read`, `mispronounced_thursday`, `read_then_silence`: one segment each,
    ~138 ms–2550 ms (manifest 300–2320 ms plus the 150 ms pad).
  - `noisy_read` also gives one segment.
  - `silence` and `noise` give none (max probability 0.02 / 0.04).
- **Quality check** matches every fixture's `expectedQuality` in the manifest.
  Peak is within 0.2 dB of the manifest. SNR estimates:

  | Fixture | SNR estimate | Result |
  | --- | --- | --- |
  | clean | 76 dB | ok |
  | noisy_read | about 9 dB | tooNoisy |
  | noise | about 0 dB | tooNoisy |
  | quiet | peak -40 | tooQuiet |
  | silence | peak -90 | tooQuiet |

  - The SNR method needs no VAD. It takes 20 ms frame powers, uses the 10th
    percentile as noise and the 95th as speech plus noise, then
    SNR = 10·log10(S+N / N − 1).
  - If both checks fail, too quiet takes priority.
- **Fixture model**: `test/engine/audio/fixtures/tiny_vad.onnx` (550 B; Silero I/O,
  energy "probability") and `not_vad.onnx` (error path). Rebuild with
  `.venv/bin/python test/engine/audio/fixtures/make_tiny_vad.py` (needs `onnx`,
  `numpy`). `integration_test/A1-audio/fixture_audio_data.dart` embeds it and
  `clean_read.wav` as base64. Regenerate it if either changes.

## Decisions

- **Raw PCM stream and our own WAV writer**, not `record`'s file mode. One pass gives
  us the file, the level, the live VAD and the samples for the quality check. The
  writer patches the RIFF sizes on close, and the decoder also accepts a header left
  at size 0 (crash).
- **Live VAD runs on the calling (UI) isolate**: one ORT call per 32 ms chunk, with
  one intra-op thread. This is simple and keeps `silenceDetected` synchronous with the
  audio. See known gaps for the cost.
- Segmenting follows Silero's `get_speech_timestamps`: threshold 0.5, neg threshold
  0.35, minimum speech 250 ms, minimum silence 100 ms. It then pads by 150 ms, merges
  overlaps and clamps to `clip.duration`. All of it is in `VadSettings`.
- The level is the RMS of each 50 ms window. Leading silence gives 0.
- Stream errors from the plug-in are swallowed: the take keeps what it has.
  `cancel()` deletes the partial file, and a mic start failure leaves no file.
- Who deletes old recordings (`UserProfile.keepRecordings`) is not A1's job. The files
  stay in `recordings/` until C2, U2 or I1 delete them.

## Known gaps

- **On-device tests not run.** There is no Android SDK, emulator or Xcode here.
  `integration_test/A1-audio/` was analysed only. These are unverified:
  - `record` 7 streaming on API 34;
  - the `permission_handler` iOS Podfile macro (contract request 3);
  - `DynamicLibrary.process()` resolving ORT symbols on iOS (the same risk A2 raised).
- **Silero model not bundled yet**: this needs contract request 1. Until then the app
  uses the energy fallback (`await recorder.vadName` returns `"energy"`).
- **UI-isolate VAD cost**: 2.9 ms per 32 ms chunk on this loaded x86 host. Silero is
  usually well under 1 ms on a quiet desktop and about 1 ms on phones, but this has
  not been measured on a device. If U2 sees jank, move `ChunkedVad` into a
  long-lived worker isolate. Only `CoachAudioRecorder._onAudio` changes.
- **The SNR estimate is a heuristic.** A recording with no pause at all (speech from
  the first to the last frame) under-reads SNR. Steady noise just below speech level
  can look like speech to the percentile method. I2 should check the 15 dB threshold
  against real phone recordings.
- `record` with `audioInterruption: pause` pauses the stream on a phone call. The take
  then simply has a gap, and nobody is notified.
- Contract requests: `docs/contract-requests/A1-audio.md`:
  1. manifest entry for the Silero model;
  2. `docs/licences.md` row;
  3. iOS Podfile `PERMISSION_MICROPHONE=1`;
  4. provider wiring for I1.
